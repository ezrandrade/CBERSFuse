CBERSFuse

Composição RGB e fusão pancromática em lote no QGIS 4.

Desenvolvedor: Esdras Andrade, do Instituto de Geografia, Desenvolvimento e Meio Ambiente da UFAL.

Instalação

  1. Abra Complementos → Gerenciar e Instalar Complementos → Instalar a partir de ZIP.
  2. Selecione CBERSFuse_QGIS4_v1.0.1.zip, sem descompactar.
  3. Instale e ative CBERSFuse.

A ferramenta fica no menu Raster → CBERSFuse, na barra de ferramentas e na Caixa de Ferramentas de Processamento.

Como executar

  1. Abra Composição RGB + fusão PAN.
  2. Indique a pasta das cinco bandas descompactadas e uma nova pasta de saída.
  3. Mantenha R=B3, G=B2 e B=B1 para cor natural; para falsa cor, selecione R=B4, G=B3 e B=B2.
  4. Clique em Executar. A imagem RGB + PAN será adicionada ao projeto se o carregamento estiver marcado.

Os arquivos devem terminar em _BAND0.tif a _BAND4.tif, com o mesmo prefixo CBERS_4A_WPM_..., dentro da mesma pasta. A busca em subpastas é opcional.

Produtos

ProdutoPixelAdicionado ao projeto
Empilhamento B1/B2/B3/B48 mNão
Composição RGB8 mNão
Composição RGB + PAN2 mSim, se solicitado

Os três produtos são salvos como GeoTIFF, com estilos .qml. A aparência é definida pelo padrão do QGIS. Não existem campos de referência ou percentis de contraste.

Condições de uso

As quatro bandas multiespectrais precisam estar na mesma grade. Todas as bandas devem usar o mesmo SRC projetado em metros, com metadados de tipo de dados e NoData compatíveis. A validação não comprova o corregistro. Recomenda-se produto L4.

A fusão usa Weighted Brovey do GDAL, com as quatro MS e pesos iguais padrão, seguida de seleção RGB. Para índices espectrais e análises quantitativas, conserve os dados originais. O produto de 2 m não equivale a uma aquisição de 0,5 m.

Se algo impedir a execução

  • GDAL indisponível: ative o complemento Processamento e seu provedor GDAL.
  • Saída existente: selecione uma nova pasta; os produtos não são sobrescritos.
  • Permissão no Flatpak: selecione pastas acessíveis pelo próprio QGIS.
  • Cena incompleta ou incompatível: consulte os avisos e o registro JSON salvo na saída.
